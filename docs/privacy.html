Polityka prywatności – Misza

Ostatnia aktualizacja: 19 października 2026

Kto korzysta z aplikacji

Misza to prywatne narzędzie stworzone wyłącznie na potrzeby jego autora. Nie jest oferowane innym osobom.

Jakie dane są przetwarzane

Aplikacja korzysta z Gmail API w zakresie tylko do odczytu

Jak dane są wykorzystywane i przechowywane

  • Dane są przetwarzane wyłącznie na urządzeniu autora i służą tylko do opisanego wyżej celu.
  • Dane nie są sprzedawane, udostępniane ani przekazywane osobom trzecim.
  • Dane nie są wykorzystywane do reklam ani do trenowania modeli uczenia maszynowego.
  • Tokeny dostępu są przechowywane lokalnie z ograniczonymi uprawnieniami do plików.

Zgodność z zasadami Google

Wykorzystanie danych otrzymanych z interfejsów API Google jest zgodne z Google API Services User Data Policy, w tym z wymogami Limited Use.

Cofnięcie dostępu

Dostęp aplikacji można w każdej chwili cofnąć na stronie myaccount.google.com/permissions.
